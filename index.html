자주 묻는 질문

NeuroLearn은 어떤 서비스인가요?

AI가 학습자의 취약점을 자동 진단하고, 교재/영상을 자동 연결하며, 망각곡선 기반 최적 복습 스케줄을 설계하는 스마트 자격증 학습 플랫폼입니다.

어떤 자격증을 지원하나요?

현재 컴퓨터활용능력 2급 실기(엑셀)에 특화되어 있으며, 향후 정보보안기사, 워드프로세서 등으로 확장할 예정입니다.

개인 정보는 안전한가요?

소셜 로그인 기반으로 최소한의 정보만 수집하며, 결제는 외부 전문 PG를 통해 안전하게 처리됩니다.

모바일에서도 사용할 수 있나요?

PWA(Progressive Web App) 방식으로, 별도 앱 설치 없이 모바일 브라우저에서 바로 사용할 수 있습니다.

언제 오픈하나요?

2026년 7월 정식 오픈 예정입니다. 미리 체험 예약을 하시면 오픈 시 가장 먼저 초대해 드립니다.

무료로 사용할 수 있나요?

기본 진단과 학습 경로 설계는 무료입니다. 프리미엄 콘텐츠와 심화 분석은 유료 플랜에서 제공됩니다.
